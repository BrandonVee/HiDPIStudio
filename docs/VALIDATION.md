# 验证范围

测试环境：macOS 26.4，Apple M5 Pro。最低构建目标 macOS 13+，不表示所有 macOS 13+ 机器均已完成硬件验证。

## v2.4.0 发布检查（2026-11-10）

- 本地执行 `./scripts/package.sh` 成功；`--test-ci` 的 HiDPI/计时、亮度联动、自动恢复、亮度键、DDC 协议、收藏、布局和虚拟屏幕定义检查通过。使用隔离偏好和模拟 I/O，不创建虚拟屏幕，不写入实体模式或硬件亮度。
- ARM64 架构、应用签名、ZIP 解压后签名和 SHA256 校验通过；版本号不匹配时在构建前拒绝。
- GitHub Actions 配置通过 `actionlint`，构建与打包脚本通过 `shellcheck`。
- 实际打开打包后的应用，核对主窗口与当前内置屏状态；菜单栏控制中心的初次视觉检查后修正了亮度滑杆刻度与收藏/预设卡片布局。新版完整交互、多屏与长期运行仍未完成硬件覆盖。
- 云端 CI 和 Release 结果以 GitHub Actions 对应标签的运行记录为准。

## 既有硬件验证

- 原生隐藏 HiDPI：Q27G2SG4B+，桌面 2560×1440、backing 5120×2880、144 Hz，无镜像；试用恢复及 GUI 退出后保留成功。
- 原生公开 HiDPI：M27P6，桌面 2560×1440、backing 5120×2880、144 Hz，文字观感改善经使用者确认。
- 系统亮度：内置屏读取、调节、读回与恢复成功。
- DDC：24B2W1 实际亮度 50→49→50，CLI 与界面写后读回成功。
- 亮度联动：Q27G2SG4B+ 由 34/100→35/100，读回后恢复原值；使用隔离偏好。
- 虚拟 HiDPI：60、120、144 Hz 创建、源刷新率、镜像方向、恢复和清理通过。
- 确认后退出保留、未确认退出恢复、显式恢复后退出的子进程回归通过；虚拟测试使用登录会话保存，避免写入永久物理配置。
- 收藏/预设持久化、协议校验、布局几何、取消、热插拔身份及自动化策略检查通过。
- 原生亮度键的解码、修饰键、长按目标锁定、阻塞与释放通过纯逻辑测试。
- 实际窗口及 900×720 离屏排版检查完成。

## 尚未完整验证

- 真实睡眠/唤醒、快速拔插、长期运行和各种扩展坞组合。
- 授权后的实体 F1/F2 事件拦截。
- 画中画的实际帧流和权限撤销场景；实现与界面已经接入，尚未完成授权后的端到端测试。
- M27P6 的 DDC 亮度，Intel 机器，其他 macOS 版本。
- HDR/VRR 和非整数刷新率隐藏模式的广泛硬件兼容性。

未完成的硬件场景不能用纯逻辑测试结果代替。系统或显示器拒绝操作时，应用应报告实际失败并执行已有恢复路径。
